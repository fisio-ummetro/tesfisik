# Tes Fisik Fisioterapi – UM Metro

Aplikasi pemeriksaan tes fisik Prodi D3 Fisioterapi, Universitas Muhammadiyah Metro.
Halaman ini dimuat otomatis oleh aplikasi Android "Tes Fisik Fisio" sehingga pembaruan tidak memerlukan pemasangan ulang APK.

Data klien tidak disimpan di repository ini; data tersimpan di Firebase dan hanya dapat diakses melalui login.

Data wilayah Lampung: Kepmendagri No 300.2.2-2138 Tahun 2025 (github.com/cahyadsn/wilayah, MIT).
